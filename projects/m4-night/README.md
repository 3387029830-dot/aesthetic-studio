# 雨夜高架 · M4（Blender 样片）

- 场景全部由 `scripts/build.py` 生成：`source ../../env.sh && CAR_DIR=... OUT_BLEND=scene.blend blender -b --python scripts/build.py`
- 单帧试渲：`scripts/still.py`；整段逐帧渲染（可断点续渲）：`scripts/final.py`
- 10 秒 · 24fps · 1920×1080 · Cycles 96 采样 + 降噪 · 运动模糊
